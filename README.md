# موقع السندس كاربت - متابعة الإنتاج

ملف `production.xlsx` هو قاعدة البيانات. الموقع بيقراه مباشرة، وفورم التسجيل (للأدمن بس) بيبعت التسجيل لـ GitHub وGitHub Action بتضيفه للملف تلقائيًا.

## التشغيل (مرة واحدة)
1. اعمل ريبو جديد على GitHub (Public) وارفع كل محتويات الفولدر ده (بما فيها فولدر `.github`).
2. **Settings > Pages**: Source = Deploy from a branch، الفرع `main`، الفولدر `/ (root)`.
3. **Settings > Actions > General > Workflow permissions**: اختار *Read and write permissions*.
4. الموقع هيفتح على `https://USERNAME.github.io/REPO/`.

## تسجيل الإنتاج من الموقع
1. ادخل بحساب الأدمن، افتح **إعدادات الربط**.
2. اعمل Fine-grained token: GitHub > Settings > Developer settings > Personal access tokens، على الريبو ده بس، صلاحية **Contents: Read and write**.
3. الصق الرمز واضغط حفظ ثم اختبار الاتصال. الرمز بيتحفظ في متصفحك بس.
4. من **تسجيل الإنتاج اليومي** احفظ الوردية. بعد حوالي دقيقة الـ Action بتضيفها في شيت `سجل الإنتاج`.

## تعديل الملف يدويًا
لو عدّلت `production.xlsx` على جهازك، نزّل آخر نسخة من الريبو الأول (عشان ماتمسحش تسجيلات الـ Action) وبعدين ارفعه.

## اللوجو والألوان
حط اللوجو في `assets/logo.png`. الألوان كلها متغيرات في أول `css/style.css`.

## المستخدمين
الأسماء والبصمات في `js/config.js`. لتغيير كلمة سر لازم تتولد بصمة جديدة (PBKDF2-SHA256، 150000 دورة).

## تنبيه أمني
تسجيل الدخول بيخفي الصفحات فقط. لأن الريبو عام، أي حد يقدر يفتح `production.xlsx` أو الكود مباشرة. الحماية الحقيقية للكتابة هي رمز GitHub. ولتأمين القراءة لازم ريبو خاص أو استضافة بحماية حقيقية.
